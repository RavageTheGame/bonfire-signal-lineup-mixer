# Signal Mixer design context

The mixer uses the existing light Bonfire editorial style. Navy #132540 and ember #E9633F come from app/mixer.css. Helvetica and Arial support compact controls; Georgia is used in the newsletter preview. Panels use the existing 12px radius.

Reuse EditableBody for Notion body editing and option variants. Preserve the Signal masthead, email structure, responsive stacking and visible keyboard focus. New issue controls use the existing chip, action, option and section-card patterns.
